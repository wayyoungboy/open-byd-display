# GitHub项目首页设计

首页指GitHub README，不重做Android界面。保持主分支的中文README.md、英文README.en.md分工，保留同期新增的架构与致谢，加入双语导航。采用深蓝 `#101D30`、钢蓝 `#283F5D`、冰蓝 `#A9C9FF`、白色 `#F2F6FF` 与灰蓝 `#9EB5D1`。横幅使用自行绘制的车机、USB与仪表连接线框，不使用厂商标识或未经验证的实车效果图；文字为系统无衬线字体。

布局依次为：项目横幅、下载/文档/赞助导航、测试声明、当前能力、车型进度、开始使用、开发与贡献、独立性与许可。图形突出互联关系，正文保持GitHub原生Markdown的窄屏适应与深浅主题兼容。原先长篇连续介绍拆成能力和进度表，先让访客找到下载与项目实际阶段，避免把实验模型呈现为可刷固件。

```text
┌──────── 项目名称与车机—USB—仪表连接示意 ────────┐
│ 下载测试版   使用文档   反馈问题   爱发电赞助   │
├──────────────── 测试声明 ────────────────────┤
│ 当前能力 / 车型进度 / 快速使用                │
│ 开发与文档导航 / 贡献 / 许可                  │
└─────────────────────────────────────────────┘
```

不增加虚构下载量、实车截图、功能完成度或赞助者数据。保留完整测试声明、独立性说明及现有MIT/NOTICE归属。
