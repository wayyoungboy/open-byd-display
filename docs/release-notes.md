本项目为个人兴趣开发的测试版本，风险与责任限制见README和MIT许可。

0.1.1新增可关闭的开机自启、App内权限配置提示和跨平台ADB诊断脚本；自启默认关闭，仅尝试打开App。Android10及以上需要相应后台打开权限，实际车机自启效果仍待验证。GitHub项目首页重新设计，增加能力、车型进度和文档导航。

本次发布包含无登录、VIP或商业许可证的独立Android仪表更新客户端，以及源码中的电脑实验服务和FUP2组件打包工具。上传、安装分开操作；任务持久化并阻止结果不明时重复安装。签名、载荷摘要、车型与硬件校验继续保留。

研发目标为21款宋PLUS DM-i与用户提供名称的21款唐PLUS DM-i，当前尚未完成QNX原生构建与实车固件刷写。电脑实验服务只切换sandbox数据，不执行install.sh、不写车辆分区。**本Release不包含可刷仪表固件，也不声称已完成仪表投屏出画。**

APK使用独立包名org.openbyddisplay，可与小灰灰共存。开发构建artifact与正式版本APK的签名不同；日常下载以本Release内APK为准。
